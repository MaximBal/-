#Цель проекта — создание современной версии культовой игры Super Mario Bros с сохранением оригинального геймплея и добавлением инновационных механик, расширяющих игровой опыт.

#Требования 
*Python 3.12+

#Установка
*Клонируйте или скачайте этот репозиторий

#Запуск приложения
*Просто нажмите Run и игра запустится 

#Как Это Работает
*Мы использовали библиотеку Arcade для создания этой игры а также мы разбили игру на классы для читабельности кода
